# 📝 Smart Todo List

A lightweight, responsive, and persistent task manager built with **HTML5, CSS3, and Vanilla JavaScript**. Tasks are automatically saved to browser `localStorage` and can be filtered, edited, and managed with ease.

---

## ✨ Features

- **Local Storage Persistence**: Tasks automatically persist across browser restarts and reloads.
- **Filter Tabs**: Quickly view "All", "Active", and "Done" tasks with real-time counter badges.
- **Inline Task Editing**: Double-click any task description to edit and update text in-place.
- **Clear Completed Tasks**: Easily clean up finished tasks in one click.
- **Keyboard Shortcuts**: Press `Enter` to create/save tasks, and `Escape` to cancel editing.
- **Mobile Responsive**: Clean card layout designed for both desktop and mobile screens.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern Flexbox, gradients, and CSS custom properties
- **Vanilla JavaScript**: Pure DOM manipulation and Web Storage API (`localStorage`)
